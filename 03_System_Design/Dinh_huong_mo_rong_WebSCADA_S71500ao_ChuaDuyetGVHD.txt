===============================================================
PHẦN A — KIẾN TRÚC 4 TẦNG (Web SCADA qua Web API tích hợp sẵn của S7-1500)
===============================================================

Sơ đồ tổng quan:
[Động cơ + VFD] -> [PLC S7-1200 CPU1211C thật] -> [PLC S7-1500 ảo, PLCSIM Advanced] -> [Web SCADA: HTML/CSS/JS]

Tầng 1 — Động lực & chấp hành: động cơ 3 pha KĐB, biến tần (VFD), cảm biến CT/PT/module đo.

Tầng 2 — Thu thập & điều khiển thực tế: PLC S7-1200 CPU1211C — đọc cảm biến (dòng/áp/tốc độ), xuất
lệnh điều khiển VFD (chạy/dừng/đảo chiều/tăng-giảm tốc), xử lý logic bảo vệ (quá dòng, quá nhiệt).

Tầng 3 — Đồng bộ & cổng dữ liệu trung gian (Edge Gateway / Virtual Twin): máy tính chạy PLCSIM
Advanced tạo PLC S7-1500 ảo. Truyền thông S7-1200 <-> S7-1500: qua Ethernet, dùng khối lệnh PUT/GET
hoặc TSEND/TRCV để PLC 1200 thật đẩy dữ liệu thô lên PLC 1500 ảo. S7-1500 ảo đóng vai trò Web API
Server công nghiệp cho tầng Web SCADA.

Tầng 4 — Giao diện giám sát (Web SCADA): tự viết trang Web bằng HTML/CSS/JavaScript. Cơ chế lấy dữ
liệu: kích hoạt tính năng Web API có sẵn trên PLC S7-1500 ảo (đây là tính năng chính hãng Siemens,
không phải server tự viết riêng); trang Web dùng JavaScript (hàm fetch) gửi yêu cầu dạng JSON-RPC
2.0 (phương thức PlcProgram.Read và PlcProgram.Write) tới địa chỉ IP của PLC ảo để đọc/ghi dữ liệu.

Lộ trình đề xuất (CHƯA xác minh tiến độ thật — xem cảnh báo bên dưới):
1. Cấu hình PLC S7-1200, tạo PLC S7-1500 ảo trên PLCSIM Advanced, thiết lập truyền thông PUT/GET
2. Đấu nối PLC S7-1200 với VFD, cài tham số để PLC kích chạy/đổi tốc độ động cơ thật
3. Bật Web Server + Web API trên S7-1500 ảo, phân quyền User đọc/ghi, tạo DB chuẩn lưu thông số
4. Viết code Web HTML/JS đọc thử 1 biến (VD tốc độ) từ PLC ảo lên trình duyệt qua API
5. Hoàn thiện giao diện Web (đồ thị, nút bấm) và viết báo cáo NCKH

⚠️ CẢNH BÁO — file gốc ghi "Bước 1 đã xong 50%" (đã thiết lập PUT/GET giữa 2 PLC mượt mà). Claim này
CHƯA xác minh được trong phiên hiện tại — phần này rơi đúng vào phạm vi dữ liệu số đã mất (khớp mô
tả "Test A đã chạy thành công qua PLCSIM Advanced" trong NCKH_khoi_phuc/CHANGELOG.md bổ sung 45,
cũng chưa xác minh). Không coi là đã hoàn thành cho tới khi tự làm lại và xác nhận trên máy thật.

===============================================================
PHẦN B — DANH MỤC KHÍ CỤ ĐIỆN (đối chiếu, phần lớn đã xác nhận qua ảnh thật — xem 04_Hardware/)
===============================================================

1. Đóng cắt & bảo vệ nguồn (mạch động lực): Aptomat 3 pha, Contactor (PLC điều khiển cấp/ngắt
   nguồn VFD từ xa để cách ly khi khẩn cấp), Rơ-le nhiệt (bảo vệ vật lý độc lập, dù VFD đã có bảo
   vệ quá tải điện tử riêng).
2. Bảo vệ mạch điều khiển & thiết bị số: MCB 1 pha (nguồn điều khiển 220VAC), nguồn tổ ong 24VDC
   (cấp PLC + relay trung gian), relay trung gian 24VDC (cách ly PLC output khỏi cuộn hút
   Contactor/VFD, bảo vệ PLC khi có sự cố chập mạch động lực), cầu chì cho tín hiệu cảm biến/analog.
3. Đo lường & thu thập dữ liệu: CT (biến dòng, hạ dòng lớn về dải đo được), đồng hồ đa năng công
   nghiệp (nhận CT, đo áp/dòng/cosφ/công suất, giao tiếp Modbus RTU/RS485 về PLC).
4. Điều khiển tại chỗ & cảnh báo: E-Stop (cắt cơ học ngay, không qua phần mềm), nút Start/Stop tại
   chỗ (chế độ Manual dự phòng khi mất mạng/lỗi SCADA), đèn báo pha R-S-T + đèn báo Run/Fault.

Bảng luồng kết nối lên SCADA:
| Thiết bị | Tín hiệu về PLC | Hiển thị trên Web SCADA |
|---|---|---|
| Tiếp điểm phụ MCCB/MCB | DI | Nguồn tủ điện: ON/OFF |
| Tiếp điểm phụ Contactor | DI | Trạng thái cấp nguồn VFD: READY/NOT READY |
| Tiếp điểm lỗi rơ-le nhiệt (95-96) | DI | Báo động: OVERLOAD FAULT |
| Đồng hồ đo điện | Modbus RTU/RS485 | Đồ thị dòng/áp/công suất |
| VFD | Analog Out (tốc độ)/truyền thông | Tần số chạy (Hz), tốc độ thực (RPM) |
